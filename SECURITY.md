# Security Policy

## Reporting a Vulnerability

If you find a security issue, please do not open a public issue with exploit details. Contact the maintainer privately through the email listed on the GitHub profile, then include:

- A short description of the issue
- Steps to reproduce
- Impact and affected area
- Suggested fix, if known

## Scope

Security-sensitive areas may include audio uploads, generated speech, speech-to-text output, API keys, and user-provided content.

## Privacy Handling

Never commit private audio, transcripts, `.env` files, API keys, generated exports, or user data. Use short synthetic samples for demos.
